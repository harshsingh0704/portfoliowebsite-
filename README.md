# Harsh Singh — Brutalist Portfolio

A responsive React + Vite + Tailwind CSS + Framer Motion portfolio inspired by a dark amber brutalist visual direction.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Before publishing

- Replace `hello@example.com` with your actual email (3 occurrences in `src/main.jsx`).
- Replace the generic LinkedIn URL with your profile URL.
- Add the real project description and link for CodeVerse.
- Add your actual internship employer, position, and dates in the Experience section.
- Add a resume PDF link if you want a downloadable resume button.

## Build

```bash
npm run build
```

The `dist/` folder is ready for deployment to Vercel, Netlify, or Cloudflare Pages.
